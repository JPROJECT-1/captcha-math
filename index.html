YCYL MathCAPTCHA API

Ini adalah contoh implementasi dari class MathCAPTCHA. Anda dapat mengkonfigurasi widget ini melalui parameter JSON saat inisialisasi.

Parameter Konfigurasi (Settings):

  • containerId: (Wajib) ID HTML elemen untuk meletakkan widget.
  • mode: 'light', 'dark', atau 'auto' (Mendeteksi tema OS/Browser).
  • level: Tingkat kesulitan soal.
    1 (Aritmatika), 2 (Akar & Pangkat), 3 (Aljabar), 4 (Trigonometri), 5 (Peluang), 6 (Vektor), 7 (Kalkulus), atau 'random'.
  • language: Bahasa widget.
    'id' (Indonesia), 'en' (Inggris), 'auto-user' (Bahasa browser pengguna), 'auto-web' (Atribut html lang).
  • maxAttempts: Angka maksimal percobaan gagal sebelum akses diblokir (Default: 5).
