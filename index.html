Cara Memasang API

Implementasi bersih berbasis Vanilla JavaScript Class (ES6). Aman dari manipulasi Console browser karena menggunakan Private Fields (#).

1 Siapkan Container HTML

Buat sebuah elemen <div> kosong dengan ID unik di lokasi formulir (form) Anda. Widget akan dirender secara otomatis di dalam div ini.

<!-- Letakkan di dalam form Anda -->
<div id="my-captcha-box"></div>

<!-- Sertakan file library MathCAPTCHA -->
<script src="https://jproject-1.github.io/captcha-math/api.js"></script>

2 Inisialisasi Script (Settings)

Panggil class MathCAPTCHA dan masukkan konfigurasi JSON Anda. Setiap baris pengaturan dijelaskan pada komentar di bawah ini:

const myCaptcha = new MathCAPTCHA({
    
    // [WAJIB] ID dari div kosong yang telah Anda buat di HTML.
    containerId: 'my-captcha-box',
    
    // [OPSIONAL] Pilihan Tema: 'light', 'dark', atau 'auto' (mengikuti preferensi OS)
    mode: 'auto',
    
    // [OPSIONAL] Pilihan Bahasa UI. 
    // Mendukung: 'id', 'en', 'es', 'zh', 'ar', 'fr', 'de', 'ja', 'ru', 'hi'.
    // Atau gunakan 'auto-web' agar widget mendeteksi <html lang="..."> otomatis.
    language: 'id',
    
    // [OPSIONAL] Tingkat Kesulitan Soal.
    // Angka 1 sampai 7 (1: Aritmatika, 7: Kalkulus). Gunakan 'random' untuk acak.
    level: 'random',
    
    // [OPSIONAL] Toleransi kesalahan maksimal sebelum tombol dan akses diblokir permanen.
    maxAttempts: 5,

    // ========================================================
    // CALLBACK EVENTS (Menerima parameter 'response' format JSON)
    // ========================================================

    // Dijalankan HANYA jika verifikasi BERHASIL sempurna.
    onSuccess: (response) => {
        console.log("Verifikasi Sukses!", response);
        
        // Contoh Aksi: Aktifkan tombol Submit form Anda
        // document.getElementById("btn-submit").disabled = false;
        
        // PENTING: Response akan mengembalikan 'response.data.token'.
        // Kirim token ini ke backend (PHP/NodeJS) Anda untuk divalidasi.
    },

    // Dijalankan setiap kali pengguna SALAH memilih jawaban.
    onFail: (response) => {
        console.warn("Jawaban salah, coba lagi.", response);
    },

    // Dijalankan jika pengguna melebihi maxAttempts (Gagal terus).
    onBlocked: (response) => {
        console.error("Akses ditolak karena indikasi Bot.", response);
    }
});
