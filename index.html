Cara Memasang API

Implementasi bersih berbasis Vanilla JavaScript Class (ES6). Bebas library tambahan, aman dengan Private Fields (#).

1 Siapkan Container HTML

Buat sebuah elemen div kosong dengan ID unik di lokasi formulir Anda. Widget akan dirender secara otomatis di dalam div ini.

<!-- Letakkan di dalam form pendaftaran/login Anda -->
<div id="my-captcha-box"></div>

<!-- Sertakan file library MathCAPTCHA di bagian bawah body -->
<script src="https://jproject-1.github.io/captcha-math/api.js"></script>

2 Inisialisasi Script (Settings)

Panggil class MathCAPTCHA dan masukkan konfigurasi. Sistem Callbacks akan mendengarkan setiap aksi yang dilakukan pengguna.

const myCaptcha = new MathCAPTCHA({
    
    containerId: 'my-captcha-box',
    mode: 'auto', // 'light', 'dark', 'auto'
    language: 'id', // 10 Languages supported
    level: 'random', // 1-7 or 'random'
    maxAttempts: 5,

    onSuccess: (response) => {
        console.log("Sukses!", response);
        // Kirim 'response.data.token' ke backend untuk validasi
    },

    onFail: (response) => {
        console.warn("Salah tebak.", response);
    },

    onBlocked: (response) => {
        console.error("Diblokir permanen.", response);
    }
});
